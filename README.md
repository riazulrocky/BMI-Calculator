💪 BMI CALCULATOR APP (FLUTTER)

A modern and user-friendly BMI Calculator built with Flutter.  
This app calculates Body Mass Index (BMI) using height and weight, and provides detailed health tips based on the result.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## ✨ Features

| What you get | Details |
|--------------|---------|
| 🚻 Gender Selection | Choose Male or Female |
| 📏 Height Control | Adjustable slider (in centimeters) |
| ⚖️ Weight & Age | Increase or decrease using + / – buttons |
| 🧮 Instant Calculation | Calculates BMI in real-time |
| 📊 Result Page | Shows BMI value, category, and health tips |
| 🎨 Modern UI | Clean, responsive Material Design interface |

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## ⚙️ How It Works

1. Select your gender  
2. Adjust your height, weight, and age  
3. Tap **Calculate**  
4. View your BMI value, category (Underweight, Normal, Overweight, Obese), and personalized advice  
5. Tap **Re-Calculate** to go back and modify your inputs

## 📊 BMI Categories (WHO Standards)

| BMI Range | Category |
|------------|-----------|
| < 16.0 | Severe Thinness |
| 16.0 – 16.9 | Moderate Thinness |
| 17.0 – 18.4 | Mild Thinness |
| 18.5 – 24.9 | Normal |
| 25.0 – 29.9 | Overweight |
| 30.0 – 34.9 | Obese (Class I) |
| 35.0 – 39.9 | Obese (Class II) |
| ≥ 40.0 | Obese (Class III) |
