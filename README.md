BMI Calculator App

A modern and user-friendly BMI Calculator built with Flutter. 
This app calculates Body Mass Index (BMI) using height and weight, and provides detailed health tips based on the result.

Features:
- Gender selection (Male / Female)
- Height adjustment with a slider (cm)
- Weight and age adjustment with + / - buttons
- Instant BMI calculation
- Detailed result page with BMI value, category, and health tips
- Clean and responsive Material Design UI

How it works:
1. Select your gender
2. Set your height, weight, and age
3. Tap "Calculate"
4. View your BMI value, category (Underweight, Normal, Overweight, Obese), and personalized health advice
5. Use "Re-Calculate" to go back and change values

BMI Categories (based on WHO standards):
- < 16.0 : Severe Thinness
- 16.0 – 16.9 : Moderate Thinness
- 17.0 – 18.4 : Mild Thinness
- 18.5 – 24.9 : Normal
- 25.0 – 29.9 : Overweight
- 30.0 – 34.9 : Obese (Class I)
- 35.0 – 39.9 : Obese (Class II)
- >= 40.0 : Obese (Class III)
